# 설문 집계기 설계서

## 1. 목적

과학관 직원이 엑셀에서 만족도 설문 응답을 복사해 붙여넣으면, 문항별 결과 표가 바로 나오는 도구.

- 응답: 1~5점 척도, 문항 약 10개
- 붙여넣은 데이터는 브라우저 밖으로 나가지 않고, 어디에도 저장되지 않는다.
- 컴퓨터와 휴대폰에서 모두 쓸 수 있다.

## 2. 만드는 방식

- 앱은 의존성 없는 HTML 파일 하나다. 설치나 빌드 없이 브라우저로 열면 바로 동작한다.
- 외부 라이브러리, 외부 글꼴, 분석 도구를 쓰지 않는다.
- 계산 로직은 화면 코드와 떼어 둔다.
- 자동 시험은 별도 시험 파일에 둔다. 이 파일은 앱 HTML에서 계산 부분만 읽어 node로 돌린다. 직원이 쓰는 화면에는 시험이 보이지 않는다.

## 3. 입력

| 항목 | 정한 내용 |
|---|---|
| 붙여넣는 범위 | 머리글 줄까지 함께 붙여넣는다 |
| 구분자 | 탭만 받는다(엑셀·구글 시트에서 복사한 형식) |
| 첫 열 | 응답번호이므로 집계하지 않는다 |
| 문항 이름 | 머리글 줄의 둘째 칸부터 가져온다 |
| 칸 수가 머리글보다 적은 줄 | 모자란 칸은 빈 응답으로 센다 |
| 칸 수가 머리글보다 많은 줄 | 남는 칸은 버린다(어느 문항에도 세지 않는다) |
| 모든 칸이 빈 줄 | 응답으로 치지 않고 무시한다 |
| 집계 시점 | 입력창 내용이 바뀌면 곧바로 다시 집계한다 |

## 4. 데이터 처리 규칙

① **유효:** 앞뒤 공백을 지운 값이 1, 2, 3, 4, 5 중 한 글자일 때만 유효로 보고 평균에 넣는다.
② **빈 응답:** 비어 있거나 공백만 있는 칸은 빈 응답으로 따로 센다.
③ **제외:** 그 밖의 값(범위 밖 숫자, 4.0, 글자)은 제외로 따로 센다.

- 유효가 0이면 평균 칸에 "-"를 표시한다.
- 평균은 소수 셋째 자리에서 반올림해 둘째 자리까지 보인다(예: 3.00).

## 5. 결과 표

- 문항마다 한 줄이며, 순서는 머리글 순서를 따른다.
- 열은 **문항 · 유효 응답 수 · 평균 · 빈 응답 수 · 제외 수**다. 그 밖의 열이나 요약 줄은 넣지 않는다.
- 내보내기 기능(복사 버튼, 인쇄용 화면)은 두지 않는다.
- 좁은 화면에서도 같은 표를 쓴다. 문항 열은 고정하고, 숫자 열만 표 안에서 가로로 밀어 본다.

## 6. 시험 사례

### 내 카드(사용자가 정한 사례)

문항 하나의 칸 값을 아래처럼 넣었을 때의 결과다.

| 사례 | 입력 | 유효 | 빈 응답 | 제외 | 평균 |
|---|---|---|---|---|---|
| 1 | 1, 2, 3, 4, 5 | 5 | 0 | 0 | 3.00 |
| 2 | 5, (빈칸), 3 | 2 | 1 | 0 | 4.00 |
| 3 | 4, 6, 0, 4점, 3 | 2 | 0 | 3 | 3.50 |
| 4 | (빈칸), (빈칸), (빈칸) | 0 | 3 | 0 | - |

### 질문 답에서 나온 사례(설계 중 추가)

| 사례 | 입력 | 기대 결과 |
|---|---|---|
| 5 | 칸 값 " 4 ", "4.0", "５"(전각 숫자) | 유효 1(평균 4.00), 제외 2 |
| 6 | 칸 값 3, 3, 3, 3, 3, 3, 3, 4 | 평균 3.13 (3.125를 반올림, 3.12가 아님) |
| 7 | 문항이 셋인데 어떤 줄은 응답번호와 첫 문항 값만 있음 | 그 줄의 둘째·셋째 문항은 빈 응답 1씩 |
| 8 | 엑셀 복사 끝에 빈 줄이 붙음 | 어느 문항의 빈 응답 수도 늘지 않음 |
| 9 | 첫 열에 응답번호 1~5가 있음 | 첫 열은 결과 표에 나오지 않음 |
| 10 | 문항이 둘인데 어떤 줄에 문항 값이 셋 있음(셋째 값 5) | 결과 표는 문항 두 줄뿐이고, 셋째 값 5는 어느 문항에도 세지 않음 |

## 7. 성공 확인 기준

### 계산

- [ ] 시험 명령 한 줄을 실행하면 사례 1~10이 모두 통과로 나온다.
- [ ] 계산 로직을 일부러 틀리게 바꾸면 시험이 실패로 나온다.
- [ ] 문항마다 유효 + 빈 응답 + 제외가 전체 응답 수와 같다. 전체 응답 수는 머리글과 무시한 빈 줄을 뺀 응답 줄의 수다. 사례 1~10 모두와 실제 붙여넣은 데이터에서 이 합이 맞는다.

### 화면

- [ ] 엑셀에서 머리글을 포함해 응답번호 열과 문항 10개를 복사해 붙여넣으면, 따로 누르지 않아도 문항 10줄짜리 결과 표가 나온다.
- [ ] 결과 표의 열은 문항 · 유효 응답 수 · 평균 · 빈 응답 수 · 제외 수, 이 다섯 개뿐이다.
- [ ] 입력창의 숫자 하나를 고치면 결과 표도 바로 바뀐다.
- [ ] 입력창을 비우면 결과 표가 사라지고, 붙여넣으라는 안내가 보인다.

### 데이터가 밖으로 나가지 않음

- [ ] 브라우저 개발자 도구의 네트워크 탭을 연 채 페이지를 열고 데이터를 붙여넣어도, 다른 주소로 나가는 요청이 하나도 없다.
- [ ] 비행기 모드에서 저장해 둔 HTML 파일을 열어도 모든 기능이 그대로 동작한다.
- [ ] 붙여넣은 뒤 개발자 도구의 저장소(localStorage, sessionStorage, IndexedDB, 쿠키)가 비어 있다.
- [ ] 페이지를 새로 고치면 붙여넣은 데이터가 남아 있지 않다.
- [ ] HTML 파일 안에 외부 주소(http로 시작하는 글꼴, 스크립트, 이미지 링크)가 없다.

### 휴대폰

- [ ] 폭 360px 화면에서 페이지 전체가 옆으로 밀리지 않는다.
- [ ] 같은 화면에서 문항 열은 제자리에 있고, 숫자 열만 표 안에서 가로로 밀린다.
- [ ] 휴대폰에서 복사한 시트 내용을 입력창에 붙여넣으면, 컴퓨터와 같은 결과 표가 나온다.
- [ ] 글자를 확대하지 않아도 표의 숫자를 읽을 수 있다.

## 8. 다루지 않는 것

- 탭 이외의 구분자(쉼표로 나뉜 CSV 등)
- 칸 안에 줄바꿈이 든 셀
- 점수별 분포, 비율, 전체 요약 줄
- 결과 복사, 인쇄, 파일 저장
- 입력이나 결과의 보관과 불러오기
